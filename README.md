# 🎮 Bradescard Training — Módulos Interactivos LearningAI

Aplicación web interactiva desarrollada para la adaptación de módulos de capacitación, simulación operativa y juegos educativos gamificados para la plataforma **LearningAI** en alianza con **Positivo S+ / Algar Tech**.

![React](https://img.shields.io/badge/React-19.2-61DAFB?style=flat&logo=react&logoColor=black)
![Vite](https://img.shields.io/badge/Vite-6.0-646CFF?style=flat&logo=vite&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-4.3-38BDF8?style=flat&logo=tailwindcss&logoColor=white)

---

## 🚀 Características Principales

- 🎯 **Entrenamiento Gamificado por Módulos**: Evaluación adaptativa con mecánicas de vidas, puntuación y retroalimentación instantánea.
- ⚡ **Simulación de Procesos Operativos**: Entrenamiento interactivo de flujo de prevención de fraudes y verificación de datos.
- 📱 **Interfaz Adaptativa & Responsiva**: Maquetada en React 19 y Tailwind CSS para máxima velocidad y fluidez visual.

---

## 🛠️ Tecnologías

- **React 19** & **Vite**
- **Tailwind CSS 4**
- **JavaScript ES6+**
